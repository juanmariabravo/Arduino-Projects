# Belén Navideño

El objetivo de este proyecto es crear elementos que se puedan emplear enun Belén Navideño con luces y movimiento utilizando Arduino. El Belén contará con figuras tradicionales como el Niño Jesús, María, San José, los Reyes Magos, los Pastores y algunos animales. A todo ello se le añadirán luces y movimiento para hacerlo más atractivo y realista.

## Ideas
* Crear fuego parpadeante con LEDs o con la matriz de LEDs WS2812B.
* Crear un molino de viento que gire con un motor paso a paso.
* Implementar un sistema de sonido con un buzzer para reproducir canciones navideñas.
* Implementar un reloj para que el Belén tenga un ciclo de día y noche, con luces que se enciendan y apaguen según la hora del día. También pueden sonar campanas a determinadas horas.
